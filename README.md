# my TARIFF

税関ホームページの実行関税率表（輸入統計品目表）と NACCS 用品目コード一覧を、申告で使いやすい形にまとめた検索画面です。

**▶ 開く：https://stossy1985-web.github.io/my-tariff/**

- 品名・番号（2・4・6・9・10桁）・英文で検索、NACCS用コード10桁をワンクリックでコピー
- 号ごとの表示・折りたたみ、分岐（├ └）と分岐の条件、旧品目表の区分
- 基本・WTO・特恵・暫定と各EPA税率（表示する協定は選べます）
- 特殊関税（不当廉売関税など）の対象になりうる号に印
- マイメモ・お気に入りの荷主（ブラウザ内に保存。CSVで書き出し・読み込み）

収録データ：2026年8月8日版（特殊関税は2026年10月29日時点）
